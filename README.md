💖 Welcome to 2026 – Aesthetic Landing Page

A soft, minimal, and aesthetic landing page built using HTML5 and CSS3.
This project showcases a modern glassmorphism-style card layout with a pastel theme and subtle floating bubble effects.

📌 Project Overview

Welcome to 2026 is a simple aesthetic web page that displays:

A centered gradient card

Animated floating bubbles

Soft pink background theme

Clean typography

Minimal UI design

The project focuses on visual aesthetics, layout positioning, and CSS styling techniques.

🎨 Design Concept

The design follows a:

Pastel pink color palette

Soft gradient background

Rounded card with smooth shadows

Minimal typography

Clean centered layout

It gives a modern Instagram / Pinterest-style aesthetic feel.

🚀 Features

✅ Centered glass-style card

✅ Gradient background effect

✅ Soft box shadow for depth

✅ Rounded corners (border-radius)

✅ Floating bubble decorations

✅ Responsive layout

✅ Minimal and elegant design

🛠️ Technologies Used

HTML5

CSS3

CSS Gradients

Flexbox

Box Shadow

Border Radius

CSS Positioning

Basic CSS Animations (for bubbles)

📖 Layout Explanation
1️⃣ Background

Soft pastel pink background color

Creates calm and aesthetic mood

Full-screen height using:

height: 100vh;
2️⃣ Center Card

Positioned using Flexbox (center alignment)

Rounded corners:

border-radius: 20px;

Soft gradient background inside the card

Subtle shadow for depth effect:

box-shadow: 0 10px 25px rgba(0,0,0,0.1);
3️⃣ Text Styling

Bold heading:

“Welcome to 2026 💖”

Subtext:

“Where did all the time go?”

Center aligned typography

Soft contrast colors for readability

4️⃣ Bubble Decorations

Created using small circular div elements

Positioned using position: absolute

Rounded using:

border-radius: 50%;

Optional animation using @keyframes for floating effect

📱 Responsive Design

Uses Flexbox for centering

Automatically adjusts for smaller screens

Card scales properly on mobile devices
